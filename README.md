# 工件尺寸测量 + 缺陷检测 Demo（AOI / 机器视觉）

> Python + OpenCV 实现的工业视觉检测入门项目：从一张照片里自动测出工件尺寸、检测表面缺陷。
> 涵盖机器视觉核心流程：**相机标定 → 图像分割 → 轮廓分析 → 缺陷检测**。

## 功能

| 模块 | 技术 | 说明 |
|------|------|------|
| 相机标定 | 像素 ↔ 毫米换算 | 用尺子做参考，算出 `ppm`（像素/毫米）系数 |
| 工件检测 | 颜色分割 / 阈值分割 + 轮廓 | 把工件从背景中精准抠出 |
| 尺寸测量 | 包围盒 + 圆孔检测 | 输出真实毫米尺寸 |
| 缺陷检测 | 中值滤波模板差分 | 检测划痕 / 异色斑点等表面缺陷 |

## 运行

```bash
pip install opencv-python numpy

# 内置合成图演示（一张合格、一张带缺陷）
python opencv_demo.py

# 用你自己的照片（需先标定 ppm）
python opencv_demo.py --image 你的工件.jpg --ppm 9.7

# 标定辅助：从带尺子的照片估算 ppm
python calibrate.py --image 你的工件.jpg
```

> ⚠️ **中文路径兼容**：Windows 下 OpenCV 的 `imread/imwrite` 不认中文路径，
> 本项目已用 `imdecode/imencode + tofile` 绕过，直接放中文路径也能跑。

## 效果示例

| 输入 | 输出 |
|------|------|
| 合成工件图（带划痕） | 尺寸 + NG 判定 + 缺陷红框 |
| 真实照片：红色块 + 尺子 | 尺寸 53.5×64.3mm，缺陷 0，判定 OK |

## 项目结构

```
opencv_demo.py   主程序：尺寸测量 + 缺陷检测
calibrate.py     标定辅助：从带尺子的照片估算 ppm
output/          结果图（合成图 + 真实照片验证）
```

## 适用场景

机器视觉 / AOI / 半导体设备 / 光电检测的入门学习与原型验证。
